## 📖 Panduan Berdasarkan Kebutuhan

### 🆕 Saya Pengguna Baru

**Langkah-langkah:**
1. Baca [Quick Reference Guide](QUICK_REFERENCE_GUIDE.md) (10 menit)
2. Baca [User Guide](USER_GUIDE.md) bagian Login & Dashboard (15 menit)
3. Baca bagian sesuai role Anda (20 menit)
4. Coba login dan explore sistem (30 menit)

**Total waktu:** ~1 jam

---

### 🔧 Saya Ingin Deploy Sistem

**Langkah-langkah:**
1. Baca [Deployment & Maintenance](DEPLOYMENT_AND_MAINTENANCE.md) - Pre-deployment Checklist
2. Siapkan server sesuai requirements
3. Ikuti Deployment Steps step-by-step
4. Lakukan testing sesuai checklist
5. Setup monitoring dan backup

**Total waktu:** ~4-6 jam (tergantung pengalaman)

---

### 🐛 Saya Menemukan Bug

**Langkah-langkah:**
1. Cek [User Guide](USER_GUIDE.md) - Troubleshooting section
2. Cek [Deployment & Maintenance](DEPLOYMENT_AND_MAINTENANCE.md) - Troubleshooting section
3. Cek error logs
4. Jika tidak terselesaikan, hubungi support dengan info:
   - Screenshot error
   - Steps to reproduce
   - Error logs
   - Environment info

---

### 📊 Saya Ingin Menambah Fitur Baru

**Langkah-langkah:**
1. Baca [Complete System Documentation](COMPLETE_SYSTEM_DOCUMENTATION.md) - Architecture
2. Baca [Module Specifications](MODULE_SPECIFICATIONS.md) - Pattern yang digunakan
3. Baca [Database Schema Documentation](DATABASE_SCHEMA_DOCUMENTATION.md)
4. Baca [API Endpoints Documentation](API_ENDPOINTS_DOCUMENTATION.md)
5. Follow existing patterns untuk consistency

---

### 🔍 Saya Ingin Memahami Perhitungan

**Langkah-langkah:**
1. Baca [Module Specifications](MODULE_SPECIFICATIONS.md)
2. Cari modul yang ingin dipahami
3. Lihat bagian "Auto-calculation Formula"
4. Lihat bagian "Validation Rules"
